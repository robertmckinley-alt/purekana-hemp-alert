# PureKana Hemp Alert Advertorial

Responsive Next.js advertorial funnel for PureKana THC Sleep Gummies.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy to Vercel

Import this Git repository into Vercel. Next.js is detected automatically.

## FAL image generation

The page does not require generated images to build. An optional FAL script is included for creating a Capitol hero asset. Set `FAL_KEY` in the environment and run `npm run generate:hero`.

## Conversion URL

All CTAs point to the PureKana THC Sleep Gummies product page.

## Compliance

This implementation is labeled as sponsored/advertorial and avoids unsupported medical or life-saving claims. The legal hook is the scheduled November 12, 2026 federal hemp-definition change under P.L. 119-37.
